# Game QA Portfolio – Roman-Haha

A portfolio of manual game testing: bug reports, problem isolation, and exploratory testing.

## About myself

Beginner QA game tester. Focused on exploratory testing, reducing the reproduction steps to a minimum, and preparing clear reports for developers. Below are the real bugs that I discovered, isolated, and reported.

## Skills and techniques

- Exploratory Testing
- Bug isolation: narrowing down the steps to the minimum reproduction
- Comparative testing (working object vs. broken)
- Testing boundary values (open door / closed door / doorway boundary)
- Bug report formatting: steps, expected/actual result, Severity/Priority
- Recording videos and screenshots as evidence
